# itbot

Telegram-бот: расшифровывает голосовые и кружки в чатах и отвечает на вопросы (Grok / xAI; OpenAI — запасной).
Работает **только в чатах, которые включил владелец**.

## Что умеет

- 🎙 Голосовые и видеокружки во включённых чатах расшифровываются автоматически (xAI speech-to-text, ≈ $0.10 за час;
  если xAI не ответил — OpenAI `gpt-transcribe`).
  Файлы отправляются как есть, без конвертации.
- 🚫 Медиа **не расшифровываются никогда**: mp3, музыка, аудио- и видеофайлы, GIF, документы — даже если попросить.
- 💬 Отвечает на вопросы, когда его упоминают (`@имя_бота вопрос`), отвечают на его сообщение или пишут `/ask вопрос`.
  Видит последние ~40 сообщений чата (с расшифровками), так что можно спросить «о чём было голосовое выше?».
- Ответ на голосовое или кружок с `@бот` или `/ask` — ответит по его содержанию.
- Ответ голосом на сообщение бота — бот поймёт голосовой вопрос.
- 🔎 Ищет в интернете и в X/Twitter (Grok `web_search` / `x_search`): «@бот погугли новости в США». Grok сам решает,
  когда искать (новости, цены, курсы, события); в конце ответа — ссылки на источники.
- ↩️ Тегните бота в ответ на любое сообщение — он прочитает его (текст, расшифровку голосового, фото) и ответит по нему.
- 📥 Скачивает по ссылкам и присылает в чат: Instagram (Reels, видео, фото и карусели до 10 штук), Threads (фото, видео, карусели), X, VK, Facebook, Pinterest, Twitch-клипы.
  Текст поста (подпись в Instagram, текст в Threads, X, TikTok, Reddit) приходит под медиа свёрнутой цитатой; длинный — отдельным сообщением;
  Сообщение со ссылкой бот удаляет и публикует медиа вместо него — с подписью «от кого» и комментарием
  (если в сообщении был вопрос к боту или скачать не вышло — оригинал остаётся; выключается в `/panel → 🗑`, нужно право «Удаление сообщений»).
  Ссылки `threads.com/share/…` открываются только с cookies Threads; прямые ссылки на пост работают без них.
  TikTok, YouTube Shorts и Reddit — если загрузить cookies.txt (`/panel → 🍪 Cookies`). Лимит Telegram — 50 МБ.
  yt-dlp обновляется автоматически каждую ночь (`itbot-ytdlp-update.timer`).
- 🗞 Саммари чата: `/summary` — итоги за сутки, `/summary 6` — за 6 часов; или «@бот что было за день».
  В `/panel` у каждого чата есть «🗞 Итоги дня» — бот сам публикует саммари каждый вечер (`SUMMARY_TIME`, по умолчанию 21:00).
  «📅 Итоги недели» — по воскресеньям (`WEEKLY_DAY`) в то же время: статистика + саммари недели с «сообщением недели»
  (дневные итоги в этот вечер не дублируются). `/summary неделя` или «@бот итоги недели» — по запросу.
  История хранится 8 дней (до 20000 сообщений на чат).
- 📊 Статистика: `/stats` — за неделю, `/stats 1` — за сутки; или «@бот кто больше всех пишет?».
  Топ участников, голосовые/фото/видео, самый активный день и час, «сова», что сделал бот.
- 🎨 Рисует картинки (Grok Imagine): «@бот нарисуй кота-космонавта», «@бот сделай мем про понедельник», `/draw закат над морем`.
  Ответ на фото «@бот переделай в стиле аниме» / «убери фон» / «добавь шляпу» — редактирует это фото.
  Формат: «вертикально» / «для сторис» → 9:16, «горизонтально» → 16:9, «квадрат» / «аватарка» → 1:1, или прямо `3:2`.
  Лимиты для участников: 5 картинок в час на человека и 40 в день на чат (на владельца не действуют). ~$0.04 за картинку.
- 🎬 Оживляет фото (Grok Imagine Video): ответ на фото «@бот оживи» / «пусть улыбнётся» / «сделай из этого видео», или `/video`
  в ответ на фото. Видео по описанию: «@бот сними видео, как кот играет на гитаре» / `/video …`.
  По умолчанию 6 с, можно «10 сек» (владелец — до 15). Обычно готово за 20–60 с.
  `grok-imagine-video-1.5-lite` ≈ $0.02/с (≈ $0.12 за ролик). Лимиты: 2 видео в час на человека и 10 в день на чат.
- 🔊 Голос (ElevenLabs, если задан ключ; иначе OpenAI TTS): «@бот ответь голосом, …» / «расскажи анекдот голосом» —
  ответ голосовым с текстом под ним; «@бот озвучь» в ответ на сообщение — зачитает его вслух.
  🗣 На голосовое в ответ боту (или голосовой вопрос в личке) бот отвечает голосовым — выключается в `/panel → 🗣`.
  Если ElevenLabs не ответил (ключ, баланс) — тот же ответ озвучит OpenAI, а владельцу придёт предупреждение.
- 👀 Видит изображения: фото, скриншоты, отправленные файлом (PNG/JPEG/WebP), стикеры, кадр-превью видео —
  «@бот что тут написано?», «переведи», «что за ошибка?», «посчитай чек» в ответ на картинку.
  С картинкой бот ищет в интернете, только если попросить («найди», «погугли», «сколько стоит»):
  иначе модель может искать десятки раз и перечитывать картинку — это долго и дорого.
- 🧠 Обычные вопросы — быстрая `grok-4.3`; сложные задачи — `grok-4.7` (`HARD_MODEL`): ребусы, головоломки,
  загадки и т. п. сразу идут к ней, а если `grok-4.3` сама признаёт, что задача ей не по силам
  (или вместо ответа пишет «сейчас разберу…»), вопрос передаётся `grok-4.7`.
- 🤔 Сложная задача может решаться несколько минут — бот пишет «Думаю…» через 25 с и удаляет эту заметку,
  когда ответит. Ответ ждём до 15 минут.
- В личке с владельцем: перешлите голосовое — получите текст; пишите вопросы — получите ответы.

## Управление (личка с ботом, только владелец)

`/panel` — список чатов, включить/выключить, отдельно расшифровку и ответы, очистить память, выйти из чата,
выбрать модель Grok, статистика использования. Кнопка «➕ Добавить в группу» сразу просит права администратора.

`/tease имя` (или `/panel → 😏 Сарказм`) — выбранным людям бот отвечает язвительно, а иногда и не по делу,
как будто у него такой характер. В чате это никак не видно: ни команд, ни пометок.

Когда бота добавляет **владелец** — чат включается сразу. Если добавил кто-то другой — бот выключен и присылает
владельцу кнопки «Включить / Выйти».

**Боту нужны права администратора** в группе — иначе Telegram не показывает ему голосовые.

## Сервер

- Код: `/opt/itbot`, данные (SQLite): `/opt/itbot/data`, настройки: `/opt/itbot/.env`
- Сервис: `systemctl status itbot`, логи: `journalctl -u itbot -f`
- Сменить токены: `itbot-setup` (спросит токен бота → ключ Grok → ключ OpenAI → ключ ElevenLabs и голос; Enter оставляет текущее значение)
- Обновить код с локальной машины: `deploy/deploy.sh`

## Настройки `.env`

| Ключ | Что это |
|---|---|
| `BOT_TOKEN` | токен от @BotFather |
| `XAI_API_KEY` | ключ Grok / xAI (console.x.ai) — для ответов |
| `OPENAI_API_KEY` | ключ OpenAI (platform.openai.com) — запасная расшифровка и запасной голос |
| `STT_PROVIDER` | кто расшифровывает: `xai` (по умолчанию, OpenAI — запасной) или `openai` |
| `STT_MODEL` | модель расшифровки OpenAI (`gpt-transcribe`; setup выбирает лучшую доступную) |
| `OWNER_ID` | (необязательно) Telegram ID владельца; иначе владелец назначается по ссылке из `itbot-setup` |
| `CHAT_MODEL` | модель по умолчанию (`grok-4.3`); меняется и в `/panel` |
| `HARD_MODEL` | модель для сложных задач (`grok-4.7`); пусто = не использовать |
| `HARD_REASONING_EFFORT` | глубина размышлений для неё (`medium`; на `high` ребус решался больше 12 минут) |
| `REASONING_EFFORT` | глубина размышлений Grok: пусто = по умолчанию модели (`high`), `medium`, `low` |
| `STT_LANGUAGE` | пусто = автоопределение языка; `ru` — подсказать язык (точнее и быстрее, если в чате все говорят по-русски) |
| `IMAGE_MODEL` | модель для картинок (`grok-imagine-image-2.0` ≈ $0.04; `grok-imagine-image` ≈ $0.02) |
| `VIDEO_MODEL` | модель для видео (`grok-imagine-video-1.5-lite` ≈ $0.02/с; `grok-imagine-video-1.5` ≈ $0.08/с — 1080p) |
| `TTS_MODEL`, `TTS_VOICE` | озвучка (`gpt-4o-mini-tts`, голос `marin`; ещё женские: `coral`, `nova`, `shimmer`) |
| `ELEVENLABS_API_KEY` | (необязательно) ключ ElevenLabs — голос бота; задаётся в `itbot-setup` (шаг 4) |
| `ELEVENLABS_VOICE_ID` | голос ElevenLabs (`itbot-setup` покажет список; пусто = первый женский голос аккаунта) |
| `ELEVENLABS_MODEL` | `eleven_multilingual_v2` (≈ $0.08 за 1000 символов); `eleven_flash_v2_5` — вдвое дешевле |
| `WEEKLY_DAY` | день итогов недели: 0 = понедельник … 6 = воскресенье (по умолчанию 6) |
| `SUMMARY_TIME` | время ежедневных итогов, `ЧЧ:ММ` по `TIMEZONE` (по умолчанию `21:00`) |
| `TIMEZONE` | часовой пояс для контекста (`UTC`, `Europe/Moscow`, …) |
