# itbot

Telegram-бот: расшифровывает голосовые и кружки в чатах (OpenAI) и отвечает на вопросы (Grok / xAI).
Работает **только в чатах, которые включил владелец**.

## Что умеет

- 🎙 Голосовые и видеокружки во включённых чатах расшифровываются автоматически (OpenAI `gpt-transcribe`).
  Файлы отправляются как есть, без конвертации.
- 🚫 Медиа **не расшифровываются никогда**: mp3, музыка, аудио- и видеофайлы, GIF, документы — даже если попросить.
- 💬 Отвечает на вопросы, когда его упоминают (`@имя_бота вопрос`), отвечают на его сообщение или пишут `/ask вопрос`.
  Видит последние ~40 сообщений чата (с расшифровками), так что можно спросить «о чём было голосовое выше?».
- Ответ на голосовое или кружок с `@бот` или `/ask` — ответит по его содержанию.
- Ответ голосом на сообщение бота — бот поймёт голосовой вопрос.
- 🔎 Ищет в интернете и в X/Twitter (Grok `web_search` / `x_search`): «@бот погугли новости в США». Grok сам решает,
  когда искать (новости, цены, курсы, события); в конце ответа — ссылки на источники.
- ↩️ Тегните бота в ответ на любое сообщение — он прочитает его (текст, расшифровку голосового, фото) и ответит по нему.
- 📥 Скачивает по ссылкам и присылает в чат: Instagram (Reels, видео, фото и карусели до 10 штук), X, VK, Facebook, Pinterest, Twitch-клипы;
  TikTok, YouTube Shorts и Reddit — если загрузить cookies.txt (`/panel → 🍪 Cookies`). Лимит Telegram — 50 МБ.
  yt-dlp обновляется автоматически каждую ночь (`itbot-ytdlp-update.timer`).
- Понимает фото (если спросить про фото или ответить на него).
- В личке с владельцем: перешлите голосовое — получите текст; пишите вопросы — получите ответы.

## Управление (личка с ботом, только владелец)

`/panel` — список чатов, включить/выключить, отдельно расшифровку и ответы, очистить память, выйти из чата,
выбрать модель Grok, статистика использования. Кнопка «➕ Добавить в группу» сразу просит права администратора.

Когда бота добавляет **владелец** — чат включается сразу. Если добавил кто-то другой — бот выключен и присылает
владельцу кнопки «Включить / Выйти».

**Боту нужны права администратора** в группе — иначе Telegram не показывает ему голосовые.

## Сервер

- Код: `/opt/itbot`, данные (SQLite): `/opt/itbot/data`, настройки: `/opt/itbot/.env`
- Сервис: `systemctl status itbot`, логи: `journalctl -u itbot -f`
- Сменить токены: `itbot-setup` (спросит токен бота → ключ Grok → ключ OpenAI; Enter оставляет текущее значение)
- Обновить код с локальной машины: `deploy/deploy.sh`

## Настройки `.env`

| Ключ | Что это |
|---|---|
| `BOT_TOKEN` | токен от @BotFather |
| `XAI_API_KEY` | ключ Grok / xAI (console.x.ai) — для ответов |
| `OPENAI_API_KEY` | ключ OpenAI (platform.openai.com) — для расшифровки |
| `STT_MODEL` | модель расшифровки (`gpt-transcribe`; setup выбирает лучшую доступную) |
| `OWNER_ID` | (необязательно) Telegram ID владельца; иначе владелец назначается по ссылке из `itbot-setup` |
| `CHAT_MODEL` | модель по умолчанию (`grok-4.3`); меняется и в `/panel` |
| `STT_LANGUAGE` | пусто = автоопределение языка; `ru` — подсказать язык (точнее и быстрее, если в чате все говорят по-русски) |
| `TIMEZONE` | часовой пояс для контекста (`UTC`, `Europe/Moscow`, …) |
